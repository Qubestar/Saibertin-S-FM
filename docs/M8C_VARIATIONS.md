# M8C — Fills / Accents / Variations

M8C adds destructive-but-slot-friendly transforms for quickly turning an existing pattern into a performance variation.

## Included transforms

### Fills
- Fill · Last 1 beat
- Fill · Last 2 beats
- Roll · Last step ×4

### Groove
- Ghosts · Before backbeats
- Rolling · 16ths

### Velocity / accents
- Accent · Quarter downbeats
- Velocity · Alternating
- Velocity · Crescendo

### Ratchet
- Ratchet · Every 4th active step ×2

## Scope

Transforms can target either:
- the current 16-step page; or
- the whole current track length.

## Relationship with Pattern Slots

M8C is designed to be used with M8B Pattern Slots. A typical workflow is:

1. Keep the base groove in Pattern A.
2. Duplicate A → B.
3. Apply a fill or accent transform to B.
4. Duplicate another version into C/D for rolling or ratchet variants.

Routing remains track-level and is never changed by a variation transform.

## Notes

These are practical production recipes rather than claims that one pattern is universally correct for a genre. Users can always edit the resulting steps manually after applying a transform.

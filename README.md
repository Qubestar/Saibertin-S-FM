# Saibertin S-FM

**Saibertin S-FM** is an experimental open-source MIDI controller and hardware sequencer firmware for the M-VAVE FM-1, used as a development playground for **Saibertin S1**.

Repository slug: `S1-FM`.

Initial goals:

- configurable MIDI CC output from the FM-1 controls;
- track-based USB MIDI sequencing;
- KEYS / SCALE / CHORD / DRUM / SEQ modes;
- Note Repeat, Arp and Scatter-style performance tools;
- browser companion / emulator;
- a modular architecture that can later inform a Saibertin community SDK/custom-mode ecosystem.

Development is currently in **M0 — Foundation**. See `docs/PROJECT_SCOPE.md`, `docs/ROADMAP.md`, `docs/UPSTREAM.md` and `docs/REFERENCES.md`.
